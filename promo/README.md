# Agency promo video

A 32-second promotional film for Agency, built with [HyperFrames](https://github.com/heygen-com/hyperframes)
(HTML compositions rendered frame by frame to MP4). The finished film is
[`renders/agency-promo.mp4`](renders/agency-promo.mp4): 1920 × 1080, 30 fps, with music and sound effects.

Everything on screen is rebuilt from this repository's own design system and copy: the tokens in
`src/styles/tokens.css`, Geist, the outline icons and brand mark from `src/components/icon.tsx`, and the labels
used by the board, card inspector, chat, guest panel and search palette. Nothing here is part of the web app's
build, lint or tests.

## The story

One client brief is scattered across messages, email threads and files called `final_v4`. The pieces collapse
into a single card, ACME-1, which the viewer follows through the board, its checklist and comments, the
project's client chat and ⌘K search, ending on "Client work, one place." and the mark. `SPEC.md` has the shot
list with timings; `STORYLINES.md` has the two alternatives that were not built.

## Layout

| Path | What it is |
| --- | --- |
| `index.html` | Root composition: tokens, scene hosts, music and every sound-effect cue |
| `compositions/*.html` | One scene each: `hook`, `board`, `inspector`, `chat`, `search`, `endcard` |
| `assets/fonts/` | Geist and Geist Mono (SIL OFL, `OFL-geist.txt`) |
| `assets/vendor/gsap.min.js` | GSAP, loaded locally so renders never fetch |
| `assets/sfx/` | Sound effects from Pixabay (see `CREDITS.md`), plus pitched variants made with FFmpeg |
| `assets/music/bed.wav` | Music bed, generated by `scripts/make_music.py` |
| `renders/agency-promo.mp4` | The rendered film |

## Edit and re-render

Needs Node 22+, FFmpeg and Chrome (or set `HYPERFRAMES_BROWSER_PATH` to a Chromium binary).

```sh
cd promo
npx hyperframes@0.8.185 preview          # Studio preview in the browser
npx hyperframes@0.8.185 check            # lint, layout, contrast and motion checks
npx hyperframes@0.8.185 render --quality delivery --output renders/agency-promo.mp4
```

Copy changes: the call to action and brand green are composition variables (`cta`, `primary`) on
`index.html`; other lines live in their scene file. Sound cues sit in `index.html` with their times, each placed
so its measured peak lands one frame after the picture it belongs to.

Music: `python3 scripts/make_music.py` (numpy, scipy, FFmpeg) rebuilds `assets/music/bed.wav` at about −16 LUFS.
To use a licensed track instead, replace that file with a 32-second track and keep the `music` element's id.
