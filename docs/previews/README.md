# UI previews

Screenshots come from Playwright journeys against the local API with disposable
accounts. Images show implemented behavior; synthetic names are test data.

Teams, sharing, the icon picker, editable List tables and board grouping were
refreshed and visually reviewed on 2026-10-21. Capture journeys wait for saved
state, the intended presentation and deliberate failure toasts to settle.

- [Inline list creation](list-created-inline.png) / [200px empty lists](kanban-empty-height.png): click Add list and name the new column directly.
- [Board filters](board-filters-light.png) / [dark](board-filters-dark.png) / [mobile](board-filters-mobile.png): right-aligned search, anchored filters and the project icon header.
- [Board skeleton, light](loading-board-light.png) / [dark](loading-board-dark.png) / [mobile](loading-board-mobile.png) / [card drawer](loading-card-dark.png): shared silhouettes reserve board/card content while real requests are pending. Captured and reviewed on 2026-10-21; reduced-motion checks ensure the pulse stops.
- [Select menu, light](select-menu-light.png) / [dark](select-menu-dark.png) / [mobile](select-menu-mobile.png): the shared select field, padded floating menu, selected-row checkmark and touch targets. Captured by `e2e/select-fields.spec.ts` on a browser supporting customizable native selects.
- Confirmation modal light/dark/mobile screenshots are generated by `e2e/confirmation.spec.ts`, which checks focus, cancellation and confirmed actions.
- [Board canvas, light](board-canvas-light.png) / [dark](board-canvas-dark.png): lighter warm sidebar palette, compact toolbar and content-sized columns.
- [Light app bar](appbar-light.png): 56px global bar and module rail with the contextual sidebar.
- [Dark Kanban](appbar-dark.png): full semantic theme and separate Add card tiles.
- [Mobile dark Kanban](appbar-dark-mobile-board.png) / [navigation](appbar-dark-mobile.png): compact board controls, labelled mode switch and global search.
- [Editable List table](list-table-desktop.png) / [dark](list-table-dark.png) / [mobile](list-table-mobile.png): inline name, assignee and due-date editing, section rows and reorder handles.
- [Populated List table](list-view-desktop.png) / [dark](list-view-dark.png) / [mobile](list-view-mobile.png): responsive labels, activity and shared board controls.
- [Project editor](project-editor.png): saved icon picker, predefined colors and live preview.
- [Team projects and stars](project-teams-light.png) / [Project sharing](project-sharing-light.png): personal Starred, team navigation and project-admin access controls. Implicit workspace administrators are absent from the direct-grant list.
- [Mobile Teams](team-settings-mobile-light.png) / [Guest invitation in dark mode](team-guests-mobile-dark.png): stacked people and access controls, full-width add-person picker and last-admin protection.
- [Assignee grouping](group-assignee-light.png) / [Due grouping in dark mode](group-due-dark.png): empty groups remain available, and drags change assignments or due dates without changing list order.
- [Grouped List on mobile](group-list-mobile-dark.png) / [Guest due grouping](group-guest-mobile.png): responsive card subrows and read-only guest tiles without assignee controls.
- [Kanban desktop](kanban-desktop.png) / [mobile](kanban-mobile.png): populated board spacing.

Icons, stars, teams and access controls use the live API. Their implementation
records are in [personalization](../handoffs/PROJECT_PERSONALIZATION.md) and
[the contract integration](../handoffs/BACKEND_CONTRACT_UPGRADE.md).
The completed [teams and grouping handoff](../handoffs/TEAMS_RELEASE_AND_BOARD_GROUPING.md)
records the capture journeys and verification commands.
